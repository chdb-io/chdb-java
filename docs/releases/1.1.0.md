# chdb-java 1.1.0

Release notes and Maven Central installation instructions for the first stable Java binding
release. Publication status and verification evidence are tracked in
[release readiness](../release-readiness.md); this document is not a publication receipt.
The `1.1.0` examples below require that version to have completed Central Portal publication.

## Release contents

- Binding version: `1.1.0`.
- Bundled engine: official chDB Core `26.11.1`, pinned by checksum.
- JNI ABI version: `5`; Java API version property: `1`.
- Java 11 or later; Java 11, 17, 21 and 25 are covered by the four-platform build matrix.
  Java 26 is a forward-compatibility check, not an additional full platform matrix.
- JDBC provides row-oriented `ResultSet` access. The optional `chdb-arrow` module provides
  Arrow batch input, typed results and bulk insertion; it remains experimental and does not
  become a standard Java ADBC driver merely by being included in this release.

Six library coordinates are published under `com.clickhouse.chdb`: `chdb-jdbc`, `chdb-arrow`,
and the four native packages below. Consumer POMs are standalone; the internal parent and
BOM are not published to Central. Use one version property rather than importing a chDB BOM.
Keep the driver, optional Arrow module and native packages on the same binding version.

| Runtime platform | Native artifact ID |
| --- | --- |
| Linux x86_64, glibc | `chdb-native-linux-x86_64-gnu` |
| Linux aarch64, glibc | `chdb-native-linux-aarch64-gnu` |
| macOS x86_64 | `chdb-native-macos-x86_64` |
| macOS arm64 | `chdb-native-macos-aarch64` |

## Install from Maven Central

Declare the package for the platform running the JVM. It brings in `chdb-jdbc` transitively.
For example, on Linux x86_64:

```xml
<properties>
  <chdb.version>1.1.0</chdb.version>
</properties>

<dependencies>
  <dependency>
    <groupId>com.clickhouse.chdb</groupId>
    <artifactId>chdb-native-linux-x86_64-gnu</artifactId>
    <version>${chdb.version}</version>
  </dependency>
</dependencies>
```

Maven Central is Maven's default repository. Do not add `maven.chdb.io` or the Central
snapshot repository for this stable version. Native packages contain the engine, so their
downloads are large; no engine download is performed by the driver at runtime.

After resolving the dependency, a JDBC smoke test is:

```java
import java.sql.Connection;
import java.sql.DriverManager;
import java.sql.ResultSet;
import java.sql.Statement;

try (Connection connection = DriverManager.getConnection("jdbc:chdb::memory:");
        Statement statement = connection.createStatement();
        ResultSet rows = statement.executeQuery(
                "SELECT count(), sum(number) FROM numbers(1000)")) {
    if (!rows.next() || rows.getLong(1) != 1000 || rows.getLong(2) != 499500) {
        throw new AssertionError("Unexpected JDBC result");
    }
    System.out.println(connection.getMetaData().getDatabaseProductVersion());
}
```

The engine version should be `26.11.1`. The same test must be repeated against actual stable
Central downloads after publication; a successful source build or snapshot test is not that
post-publication check.

## Optional Arrow support

Keep the matching native dependency above and add:

```xml
<dependency>
  <groupId>com.clickhouse.chdb</groupId>
  <artifactId>chdb-arrow</artifactId>
  <version>${chdb.version}</version>
</dependency>
```

For Arrow Java 19.0.0, run the JVM with
`--add-opens=java.base/java.nio=ALL-UNNAMED`. See the
[Arrow guide](../../chdb-arrow/README.md) for `ArrowSession`, batch ownership and close order.
JDBC-only consumers do not need the Arrow module or its dependencies.

## Compatibility and limitations

- A JVM may use multiple connections to one storage path, but not different storage paths
  at the same time. Use separate JVMs when independent engine storage paths are needed.
- A connection executes one statement at a time; result sets are forward-only and read-only.
- Transactions, savepoints and unsupported JDBC operations are not emulated. Unsupported
  operations throw `SQLFeatureNotSupportedException`; see [the JDBC scope](../unsupported.md).
- Windows, musl/Alpine Linux, 32-bit platforms, Android and GraalVM Native Image are not
  supported. See the [support matrix](../../README.md#support-matrix) for OS and JVM details.
- Engine/driver compatibility checks remain enabled. Do not mix an older RC native package
  with `1.1.0` Java modules or disable those checks as part of ordinary installation.

Native packages retain license information, the engine component inventory and a CycloneDX
SBOM in `META-INF/licenses/` and `META-INF/sbom/`. The release-owner redistribution decision
and the expressly waived RC-window, external-project acceptance and concurrent-soak gates
are recorded in [release readiness](../release-readiness.md). A waived gate is not a passed
test, and neither this document nor CI success is a legal-review claim.
